1

Pilih Metode

Buka menu Pilih Metode dari Beranda, lalu ketuk salah satu metode statistik yang tersedia (mis. Regresi Linear). Ikuti langkah 1–3: tentukan variabel, masukkan data, lalu lihat hasil perhitungan lengkap dengan tabel bantu, langkah manual, persamaan, dan interpretasi.

2

Buka menu Kuis Statistika untuk menguji pemahaman Anda. Jawab setiap soal pilihan ganda, lalu ketuk Selesai di akhir untuk melihat skor beserta pembahasan tiap soal.

Metode Statistik

Regresi Linear

Regresi linear sederhana (1 variabel X) maupun berganda (2–6 variabel X), lengkap dengan tabel bantu, langkah manual, persamaan, dan interpretasi.

Langkah 1

Tentukan jumlah variabel bebas (X)

Pilih 1 untuk regresi linear sederhana (Y atas satu X), atau lebih untuk regresi linear berganda.

Langkah 2

Masukkan data pengamatan

Tambahkan baris sesuai jumlah data (n). Minimal 3 baris data diperlukan untuk model ini.

Langkah 3

Hasil Perhitungan

Langkah 4

Uji Asumsi Regresi

Nilai uji asumsi klasik untuk model regresi yang telah dihitung, lengkap dengan hipotesis (H0 & H1), statistik uji, dan kesimpulannya.

Langkah 5

Kesimpulan Model

Ringkasan kondisi model regresi secara keseluruhan — menggabungkan kekuatan hubungan (R²), signifikansi (Uji F & Uji t), dan hasil seluruh uji asumsi klasik — untuk memutuskan apakah model layak digunakan.

Metode Statistik

Metode Smoothing

Ramalkan data deret waktu (time series) dengan Single Moving Average (SMA), Double Moving Average (DMA), Single Exponential Smoothing (SES), Double Exponential Smoothing — Holt (DES), atau Triple Exponential Smoothing — Winter (TES), lengkap dengan tabel hasil, langkah manual, grafik, dan evaluasi akurasi (MSE & MAPE).

Langkah 1

Pilih jenis smoothing & parameter

Setiap metode smoothing memerlukan parameter yang berbeda. Pilih metode sesuai kebutuhan, lalu tentukan parameternya.

n adalah banyaknya data terbaru yang dirata-ratakan untuk membentuk satu nilai ramalan. n harus bilangan bulat ≥ 2.

n adalah panjang rata-rata bergerak, dipakai dua kali berturut-turut (rata-rata dari rata-rata). n harus bilangan bulat ≥ 2. Metode ini (DMA) cocok untuk data yang memiliki tren linear. Minimal dibutuhkan 2×n periode data.

α adalah bobot pemulusan, bernilai antara 0 dan 1. α mendekati 1 membuat ramalan lebih responsif terhadap data terbaru; α mendekati 0 membuat ramalan lebih halus/stabil.

α mengatur bobot pemulusan level (nilai dasar) data, sedangkan β mengatur bobot pemulusan tren (kecenderungan naik/turun). Keduanya bernilai antara 0 dan 1. Metode ini (Holt) cocok untuk data yang memiliki tren tetapi tidak berpola musiman.

α, β, dan γ masing-masing mengatur bobot pemulusan level, tren, dan pola musiman (0–1). L adalah panjang satu siklus musim (mis. 4 untuk data triwulanan, 12 untuk data bulanan). Metode ini (Winter) cocok untuk data yang memiliki tren sekaligus pola musiman berulang. Minimal dibutuhkan 2×L periode data.

Langkah 2

Masukkan data deret waktu

Masukkan nilai data historis secara berurutan dari periode paling lama ke paling baru (mis. data bulanan/tahunan berturut-turut). Minimal 4 periode data diperlukan untuk parameter yang dipilih.
