Pilih Metode

Pilih metode statistik yang ingin Anda gunakan. Setiap metode dilengkapi tabel bantu, langkah manual, dan interpretasi hasil.

Metode Tersedia

    Metode baru akan terus ditambahkan. Tandai metode yang bertanda “Segera Hadir” untuk melihat perkembangan selanjutnya.

    Info Aplikasi

    Tentang StatCalc

    Buku kerja statistik digital untuk membantu Anda menghitung dan memahami metode statistik langkah demi langkah.

    Versi

    StatCalc 1.0 — berjalan sepenuhnya di perangkat Anda.

    Cara Kerja

    Semua rumus dihitung langsung di aplikasi tanpa memerlukan koneksi internet atau server eksternal.

    Kontak & Masukan

    Bagian ini dapat diisi dengan tautan dukungan, email, atau media sosial Anda.

    Metode Statistik

    Regresi Linear

    Regresi linear sederhana (1 variabel X) maupun berganda (2–6 variabel X), lengkap dengan tabel bantu, langkah manual, persamaan, dan interpretasi.

    Langkah 1

    Tentukan jumlah variabel bebas (X)

    Pilih 1 untuk regresi linear sederhana (Y atas satu X), atau lebih untuk regresi linear berganda.

    Langkah 2

    Masukkan data pengamatan

    Tambahkan baris sesuai jumlah data (n). Minimal 3 baris data diperlukan untuk model ini.

    Hasil Perhitungan
